1. GPIO Mode

This mode is the same as HC-SR04. The external MCU sends a trigger pulse
of more than 10us to the Trig pin; the module will output a high-level pulse
proportional to the distance, and the pulse width T can be used to calculate
the distance:

Distance = T * C / 2    (C is the speed of sound)

Speed of sound formula: c = (331.45 + 0.61 * t / °C) m/s
(where 330.45 is at 0°C)

Sound speed at 0°C:   330.45 m/s
Sound speed at 20°C:  342.62 m/s
Sound speed at 40°C:  354.85 m/s

The error of sound speed from 0°C to 40°C is about ±7%.
In practical applications, temperature compensation should be considered
if high accuracy is required.

2. UART Mode

UART Mode Baud Rate Setting: 9600 N 1

Command | Return Value | Description
0xA0 | BYTE_H, BYTE_M, BYTE_L | Distance (mm):
     |                      | ((BYTE_H << 16) + (BYTE_M << 8) + BYTE_L) / 1000
     |                      | Unit: mm
0xF1 | — | Company and version information

Connect the serial port. After the external MCU or PC sends command
0xA0, the module will return 3 distance data bytes: BYTE_H, BYTE_M, and
BYTE_L.

Distance calculation (unit: mm):
Distance = ((BYTE_H << 16) + (BYTE_M << 8) + BYTE_L) / 1000

3. IIC Mode

IIC Address: 0x57
IIC Data Format:

Write Data:
S | Slave Address | W | [small arrow symbol] | ACK | Data | ACK | Data | ACK | P
Data Transfer (N bytes + ACK)
S: Start Condition
W: Write
ACK: ACK
P: Stop Condition

Read Data:
S | Slave Address | R | [small arrow symbol] | ACK | Data | ACK | Data | NAK | P
Data Transfer (N bytes + ACK)
S: Start Condition
R: Read
ACK: ACK
NAK: No ACK
P: Stop Condition

Command Format:
Address | Command | Return Value | Description
Write Address 0xAE | 0x01 | — | Start measurement command
Read Address 0xAF |      | BYTE_H, BYTE_M, BYTE_L | Distance (mm):
                 |      |                      | ((BYTE_H << 16) + (BYTE_M << 8) + BYTE_L) / 1000
                 |      |                      | Unit: mm

Write command 0x01 to start measurement, then wait for at least 200ms
(maximum measurement time of the module).
Then read 3 distance data bytes, BYTE_H, BYTE_M, and BYTE_L.

Distance calculation (unit: mm):
Distance = ((BYTE_H << 16) + (BYTE_M << 8) + BYTE_L) / 1000

The external MCU initializes the module as output, and the module I/O pin is
held high for more than 10us. after the echo space signal is output, the MCU
sets the pin as input mode and waits for the module to output a high-level
pulse proportional to distance; after measurement is completed, the MCU sets
the pin back to output mode for the next measurement. The speed of sound can
be calculated from the pulse width “T” as shown below:

Distance = T * C / 2    (C is the speed of sound)

Speed of sound formula: c = (331.45 + 0.61 * t / °C) m/s
(where 330.45 is at 0°C)

Sound speed at 0°C:   330.45 m/s
Sound speed at 20°C:  342.62 m/s
Sound speed at 40°C:  354.85 m/s
